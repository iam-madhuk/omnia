# 🤖 Robotix - Multi-AI Platform

**Robotix** is a revolutionary AI platform that combines 15+ AI models under one unified interface. Experience the future of AI with seamless navigation between landing page and dashboard, featuring a modern, responsive design built with React and TypeScript.

## ✨ Features

- 🚀 **Multi-AI Integration**: Access 15+ AI models including GPT-4, Claude, Gemini, and more
- ⚡ **Lightning Fast**: Get responses in under 2 seconds with optimized AI routing
- 🎯 **Smart Routing**: Automatically selects the best AI model for your specific task
- 📱 **Responsive Design**: Beautiful UI that works seamlessly across all devices
- 🔐 **Secure Authentication**: Safe and secure user authentication system
- 🎨 **Modern UI/UX**: Built with Tailwind CSS and Framer Motion animations
- 📊 **Dashboard**: Comprehensive dashboard for managing AI interactions
- 👤 **Profile Management**: Complete user profile and settings management

## 🛠️ Tech Stack

- **Frontend**: React 19.1.1 + TypeScript
- **Styling**: Tailwind CSS 3.4.15
- **Animations**: Framer Motion 12.23.12
- **Build Tool**: Vite 7.1.4
- **Code Quality**: ESLint with TypeScript support
- **Package Manager**: npm

## 🚀 Quick Start

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn
- Git

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/iam-madhuk/omnia.git
   cd omnia
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**
   Navigate to `http://localhost:5173` (or the port shown in terminal)

### Available Scripts

```bash
# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview

# Run linting
npm run lint
```
